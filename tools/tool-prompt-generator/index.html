Tool-Prompt-Generator

Beschreibe deine Idee und erstelle einen Prompt für die KI deiner Wahl.

Deine Tool-Idee

Nutze erfundene Beispiele. Lass Namen und andere persönliche Daten weg.

Beschreibe Eingabe oder Klick, Reaktion des Tools und sichtbares Ergebnis.
Nenne das Tool oder füge einen Link ein. Beschreibe kurz, was dir daran gefällt. Einen Screenshot oder eine eigene HTML-Datei kannst du im KI-Chat zusätzlich anhängen.

Dein Prompt

Fülle die Felder aus. Hier erscheint der fertige Prompt.

Du kannst den Text vor dem Kopieren bearbeiten. Füge ihn anschließend in die KI deiner Wahl ein.
